# Images des démos : manifeste et prompts Flow (Nano Banana Pro)

Format de sortie : `assets/cases/<secteur>/<fichier>.webp`, 2K pour les `hero`, sinon 1K suffit.
Slots par démo (ratio Flow) : `hero` 16:9 · `ambiance` 3:4 · `detail` 1:1 · `offre-1..4` 4:3.
`(existant)` = fichier déjà sur disque, à ne pas régénérer.

Suffixe commun à chaque prompt :
> Editorial photography, natural light, 35mm lens, realistic textures and imperfections, subtle film grain, calm composition with negative space, Belgian (Wallonia) setting. No text, no logos, no watermark, no glossy CGI look, no oversaturation, no purple.
